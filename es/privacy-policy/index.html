Política de privacidad

En Solo Contactos, nos comprometemos a proteger tu privacidad. Esta política explica cómo nuestra aplicación maneja la información.

1. Recopilación y uso de información

Nuestra aplicación está diseñada para bloquear llamadas sin recopilar ni guardar tus datos personales en servidores externos.

Contactos

  • Finalidad: La aplicación necesita acceder a tu lista de contactos (permiso READ_CONTACTS) para decidir si una llamada entrante proviene de un contacto conocido.
  • Procesamiento: Este proceso ocurre completamente en tu dispositivo. No subimos ni compartimos tus contactos. Se usan únicamente localmente para decidir si una llamada se acepta o se bloquea.

Revisión de llamadas

  • Finalidad: Usamos la API de Android CallScreeningService para evaluar las llamadas entrantes.
  • Procesamiento: Los números de llamadas entrantes se procesan en tiempo real de forma local y se comparan con tu lista de contactos.

Estadísticas de uso

  • Finalidad: La aplicación registra cuántas llamadas se bloquearon cada día para mostrarte estadísticas.
  • Procesamiento: Estos contadores se almacenan localmente en tu dispositivo usando almacenamiento persistente. Solo conservamos datos de los últimos 7 días; los más antiguos se eliminan automáticamente.

2. Compartición de datos

No vendemos, intercambiamos ni compartimos información del usuario (contactos, números o estadísticas) con terceros. Todo el filtrado y procesamiento ocurre localmente en tu teléfono.

3. Conservación de datos

Todos los datos generados por la aplicación (ajustes y estadísticas) permanecen en tu dispositivo. Si desinstalas la app, se eliminan todos los datos almacenados localmente.

4. Seguridad

Valoramos mucho tu confianza al permitirnos acceder a tus contactos para filtrar llamadas, y hacemos todo lo posible por proteger esta información con medidas razonables. Sin embargo, ninguna transmisión por internet ni almacenamiento electrónico es completamente infalible.

5. Cambios en esta política

Podemos actualizar esta política de privacidad de vez en cuando. Te recomendamos revisar esta página periódicamente para ver cambios.

6. Contacto

Si tienes preguntas o comentarios sobre esta política, contáctanos en: blockcalls@infodados.com.
