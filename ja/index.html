仅限联系人 | 电话拦截

知らない番号からの着信を自動でブロックし、集中力を保ちましょう。

仅限联系人 で心の平穏を取り戻しましょう。

テレマーケティング、スパム、不明な番号による中断にうんざりしていませんか？ 仅限联系人 は、生産性とプライバシーを重視する人のための、シンプルでミニマルな解決策です。

仕組みはとても簡単です。番号が連絡先にない場合、電話は鳴りません。 アプリがあなたが邪魔される前に自動的に通話を拒否します。

なぜ 仅限联系人 なのですか？

  • 集中力の向上: 仕事中や休息中に集中したい人に最適です。
  • 完全なプライバシー: 連絡先は端末内でのみ処理されます。クラウドに送信されたり、第三者と共有されたりすることはありません。
  • シンプルさ: 保護のオン/オフを切り替えるための1つの中央ボタン。
  • 統計情報: 今日、昨日、過去7日間でどれだけの中断を防いだかを確認できます。
  • 公式技術: Android の Call Screening API を使用して、バッテリーを消耗させずに効率的に動作させます。

連絡先帳を唯一のフィルターにして、迷惑な電話にさようなら。
