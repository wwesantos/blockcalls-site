Política de Privacidade

No Só Quem Conheço, estamos comprometidos em proteger sua privacidade. Esta Política de Privacidade explica como nosso aplicativo gerencia suas informações.

1. Coleta e Uso de Informações

Nosso aplicativo foi projetado para fornecer serviços de bloqueio de chamadas sem coletar ou armazenar seus dados pessoais em servidores externos.

Dados de Contatos

  • Finalidade: O aplicativo requer acesso à sua lista de contatos (permissão READ_CONTACTS) para identificar se uma chamada recebida é de um contato conhecido.
  • Gerenciamento: Este processo ocorre inteiramente no seu dispositivo. Nós não enviamos, compartilhamos ou armazenamos seus contatos em nenhum servidor. Os dados são usados apenas localmente para decidir se permite ou bloqueia uma chamada.

Triagem de Chamadas (Call Screening)

  • Finalidade: Usamos a API CallScreeningService do Android para interceptar chamadas recebidas.
  • Gerenciamento: Os números de telefone das chamadas recebidas são processados localmente em tempo real para comparação com sua lista de contatos.

Estatísticas de Uso

  • Finalidade: O aplicativo rastreia o número de chamadas bloqueadas por dia para exibir estatísticas.
  • Gerenciamento: Essas contagens são armazenadas localmente no seu dispositivo. Mantemos apenas os dados dos últimos 7 dias; entradas mais antigas são excluídas automaticamente.

2. Compartilhamento de Dados

Nós não vendemos, trocamos ou compartilhamos qualquer informação do usuário (contatos, números de telefone ou estatísticas) com terceiros. Todo o processamento ocorre localmente no seu smartphone.

3. Retenção de Dados

Todos os dados gerados pelo aplicativo (configurações e estatísticas) permanecem no seu dispositivo. Se você desinstalar o aplicativo, todos os dados armazenados localmente serão removidos.

4. Segurança

Valorizamos sua confiança em nos fornecer acesso à sua lista de contatos para fins de filtragem e nos esforçamos para usar meios comercialmente aceitáveis de protegê-la.

5. Alterações nesta Política de Privacidade

Podemos atualizar nossa Política de Privacidade periodicamente. Recomendamos que você revise esta página regularmente para verificar quaisquer alterações.

6. Contato

Se você tiver alguma dúvida ou sugestão sobre nossa Política de Privacidade, não hesite em nos contatar em: blockcalls@infodados.com.
