仅限联系人的隐私政策

在仅限联系人中，我们致力于保护您的隐私。本隐私政策说明了我们的应用如何处理您的信息。

1. 信息收集和使用

我们的应用旨在提供来电拦截服务，不会在任何外部服务器上收集或存储您的个人数据。

联系人数据

  • 用途：应用需要访问您的联系人列表（READ_CONTACTS权限），以识别来电是否来自已知联系人。
  • 处理方式：此过程完全在您的设备上进行。我们不会将您的联系人上传、分享或存储到任何服务器。数据仅在本地用于决定允许或拦截来电。

来电筛选

  • 用途：我们使用 Android 的 CallScreeningService API 处理来电。
  • 处理方式：来电号码会在设备上实时处理，并与您的联系人列表进行比对。

使用统计

  • 用途：应用会记录每天拦截的来电数量，以便向您显示统计信息。
  • 处理方式：这些计数会使用加密的本地存储（DataStore）保存在您的设备上。我们只保留最近7天的数据；较早的记录会自动删除。

2. 数据共享

我们不会向第三方出售、交换或共享任何用户信息（联系人、电话号码或统计信息）。所有筛选和处理均在您的智能手机本地完成。

3. 数据保留

应用生成的所有数据（设置和统计信息）都保留在您的设备上。如果您卸载应用，所有本地存储的数据都会被删除。

4. 安全

感谢您信任我们并为筛选来电而授予应用访问联系人列表的权限，我们会尽力使用商业上合理的方式保护这些数据。不过，请注意，任何互联网传输或电子存储方式都无法保证百分之百安全。

5. 隐私政策的变更

我们可能会不时更新本隐私政策。建议您定期查看本页面，了解任何变更。

6. 联系我们

如果您对本隐私政策有任何疑问或建议，请通过以下邮箱联系我们：blockcalls@infodados.com。
